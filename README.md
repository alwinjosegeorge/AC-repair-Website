# EGS INDIA

Expert Air Conditioner Service & HVAC Solutions in India.

## Development

You need Node.js (v20+) and npm.

### Getting Started

```sh
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Tech Stack
- **Framework**: TanStack Start (React 19)
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Language**: TypeScript
